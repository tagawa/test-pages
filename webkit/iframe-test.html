WebKit iFrame Test

On every load, this page creates 400 about:blank iframes in a short burst, as some ad, video and carousel scripts do. Tap Start to run it again.

Optional URL parameters: count (default 400), interval in ms (default 20), mode (blank, srcdoc, url, or churn to remove each frame after 0.5 s; default blank) and resume=0 to wait for Start.
