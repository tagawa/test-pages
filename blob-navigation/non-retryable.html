How to read this: every button should land you on a page that says PASS. A blank page, a download prompt, or a tab that never loads is a FAIL. Allow popups before running A6 and A7.

A6 — window.open("") then assign location

Opens a blank tab, then points it at a blob URL created by this page.

A7 — window.open with noopener

Opens a blob URL in a new tab with no opener relationship.
